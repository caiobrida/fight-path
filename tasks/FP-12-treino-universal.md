# FP-12 — Criar treino universal de comandos

**Objetivo:** ensinar padrões de execução reutilizáveis entre personagens, separados do conteúdo específico do Ken.

**Dependências:** FP-02 e FP-11.

## Checklist

- [x] Definir primeira sequência pedagógica de direções e botões, do simples ao complexo.
- [x] Criar exercícios isolados de repetição, precisão e consistência com metas claras.
- [x] Disponibilizar instruções e feedback em `en` e `pt-BR`.
- [x] Associar cada exercício a um padrão de input verificado e aos limites do avaliador.
- [ ] Validar a clareza das instruções com pessoas que estão aprendendo. Requer sessões com jogadores reais em FP-16.

**Aceite:** é possível concluir uma trilha curta de treino universal sem escolher personagem, e os critérios de sucesso são compreensíveis.
