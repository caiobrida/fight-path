# FP-01 — Consolidar visão e regras do projeto

**Objetivo:** transformar o contexto conhecido em documentação compartilhável antes da implementação.

**Dependência:** plano de tarefas autorizado para iniciar FP-01.

**Estado:** pronta para revisão. Os arquivos foram criados; a tarefa será concluída após revisão e PR com a conta pessoal correta.

## Checklist

- [x] Criar `PRODUCT.md` com público, problema, experiência desejada, MVP e ideias futuras, distinguindo decisões de sugestões da conversa anterior.
- [x] Criar `ARCHITECTURE.md` com componentes, limites do simulador, dados, internacionalização e decisões técnicas ainda abertas.
- [x] Criar `ROADMAP.md` com fases, critérios de saída e ligação aos IDs das tarefas.
- [x] Criar `AGENTS.md` com regras de Git, fontes do jogo, `en`/`pt-BR`, Neon/Vercel e obrigação de atualizar documentação após decisões importantes.
- [x] Registrar explicitamente os pontos que exigem escolha do produto, incluindo escopo do MVP, contas e métricas.

**Aceite:** os quatro arquivos permitem que outro desenvolvedor compreenda o projeto e saiba o que está decidido ou pendente, sem depender desta conversa.
