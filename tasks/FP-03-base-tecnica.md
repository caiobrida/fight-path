# FP-03 — Escolher stack e preparar a base técnica

**Objetivo:** criar uma base web simples, extensível e compatível com implantação futura na Vercel.

**Dependência:** FP-01.

**Proposta inicial:** React, TypeScript e Vite, sugeridos na conversa anterior. Confirmar em `ARCHITECTURE.md` antes de adotá-los.

## Checklist

- [ ] Registrar a decisão de stack e os motivos, considerando o backend necessário para Neon.
- [ ] Criar a aplicação inicial com estrutura clara para interface, domínio de inputs, conteúdo e acesso a dados.
- [ ] Estabelecer layout mobile first e comportamento responsivo como requisito da base visual.
- [ ] Configurar lint, formatação, checagem de tipos e comandos de build.
- [ ] Documentar instalação local e variáveis de ambiente sem guardar segredos no repositório.
- [ ] Garantir que uma pessoa nova consiga executar o projeto seguindo o README.

**Aceite:** projeto inicia e compila localmente, apresenta uma base responsiva mobile first e não acopla o motor de inputs ao React.
