# FP-32 — Teach Street Fighter 6 systems with versioned evidence

**Status:** Awaiting owner approval. **Priority:** P2. **Dependencies:** FP-30.

## Checklist

- [ ] Establish the applicable SF6 build from official battle changes and in-game version information.
- [ ] Explain Drive and super resources, Impact, Parry, Rush, Reversal and Burnout with one small drill per topic.
- [ ] Record exact input, resource and frame claims only after current official/in-game verification; omit uncertain numbers.
- [ ] Show where resource state changes a decision, and distinguish normal, counter and punish-counter conditions when relevant.
- [ ] Add patch-review metadata and a process for marking outdated lessons unavailable or pending review.

**Acceptance:** SF6-specific rules are clearly labeled and traceable to the applicable build; the learner can recognize each presented system and test it in training mode.

**Evidence:** official references and reproducible recordings for both locales. A launch-era video alone does not validate current numeric behavior.
