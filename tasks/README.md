# Tarefas do FightPath

O [índice do plano](../TASKS.md) mostra a ordem e o estado. Cada arquivo `FP-XX` é uma unidade de trabalho que pode ser atribuída a uma pessoa ou equipe e convertida em uma issue do GitHub. Mantenha a discussão, os critérios de aceite e a evidência de conclusão associados ao mesmo ID.

O estado de cada tarefa consta em `TASKS.md`. Checklists marcadas registram trabalho verificado; configuração externa e validação em dispositivos reais continuam nos respectivos gates de publicação.

Ao iniciar uma tarefa:

1. Confirme dependências e dúvidas abertas.
2. Abra branch própria e PR para `main`.
3. Atualize o checklist da tarefa e a documentação relevante no PR.
4. Registre testes, fontes do jogo usadas e limitações conhecidas.
