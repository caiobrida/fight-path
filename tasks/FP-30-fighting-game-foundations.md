# FP-30 — Teach the first fighting-game foundations path

**Status:** Awaiting owner approval. **Priority:** P2. **Dependencies:** FP-29, FP-37 for examples.

## Checklist

- [ ] Cover notation/facing; normals, specials and supers; hit vs block; startup/active/recovery concepts; link vs cancel.
- [ ] Teach blocking, throws, anti-air and recognizing a punish opportunity with contextual risk and examples.
- [ ] Give each lesson a single learning goal, short bilingual text, captioned demonstration, common mistake, a small check and an SF6 training-mode drill.
- [ ] Verify game-specific examples with Capcom/current-game evidence and original authored teaching sources in the research register.
- [ ] Explain which ideas generalize and where defensive rules differ by game; avoid presenting SF6 rules as universal.

**Acceptance:** a new learner can read an instruction, explain hit/block and choose an appropriate basic response in the supplied examples. No numeric frame claim or move recommendation lacks supporting evidence.

**Evidence:** reviewed bilingual lesson inventory, sources/timestamps and beginner walkthrough.
