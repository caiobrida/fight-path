# FP-29 — Add the bilingual learning catalog and reader

**Status:** Approved for implementation (2026-11-17). **Priority:** P2. **Dependencies:** FP-26, FP-27 navigation contract; RESEARCH-CONTENT.md.

## Checklist

- [ ] Define versioned lesson IDs, track, level, prerequisites, objective, bilingual explanation, example, common mistake, knowledge check and in-game drill.
- [ ] Attach source claims, access date, game/build scope, media provenance and draft/reviewed/published state; exclude unverified drafts from public routes.
- [ ] Build catalog, track and lesson pages with breadcrumbs, readable widths, glossary links and next/previous navigation.
- [ ] Distinguish universal concepts, SF6 systems and Ken Classic; use canonical terminology with Portuguese explanations.
- [ ] Add schema checks for missing locale/source/media and invalid prerequisites; choose repository content first unless a CMS has a demonstrated need.
- [ ] Keep existing protected practice and account rules; define preview/read access explicitly without exposing account progress.

**Acceptance:** a reviewed sample lesson can be read in both languages and linked to a drill; a lesson without required evidence cannot be published by accident.

**Evidence:** content validation and route/locale checks. Reading completion must not be presented as execution mastery.
